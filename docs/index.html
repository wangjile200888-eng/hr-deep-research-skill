Open-source Codex Skill · HR Deep Research

把 HR 研究从概念库，推进到经营、组织与机制设计。

一个中英文双语的人力资源深度研究技能：从价值链推导组织能力，从组织能力推导组织形式与关键人才，再落到 HR 六大模块、方法论工具和实践问题。

三层研究结构

这个 skill 的目标不是罗列 HR 概念，而是让每个 HR 议题都能回答：解决什么经营问题，需要什么组织能力，采用什么组织形式，哪些岗位和人才承载，最后 HR 机制如何输出。

一、分析框架

价值链 -> 组织能力 -> 组织形式/机制 -> 关键岗位/人才 -> HR 六大模块输出。

二、方法论与工具

使用头部咨询公司和成熟管理实践中的工具，让框架可诊断、可设计、可执行。

三、实践与问题

识别真实组织中的阻力、冲突、数据争议、变革风险，并给出解决方案。

分析框架

HR 机制不是起点，而是由经营价值、组织能力和组织形式推导出来的结果。

01

价值链 · Value Chain

企业在哪里创造价值、转化价值、交付价值、损失价值？看收入、利润、现金流、客户体验、效率和风险。

02

关键组织能力 · Capabilities

为了承接价值链，组织必须持续具备什么能力？例如增长、复制、协同、创新、成本控制、客户运营。

03

组织形式与组织机制 · Organization Design

选择职能制、事业部制、矩阵制、项目制、中台、共享服务或敏捷小队，并设计权责、决策、预算、例会和问责机制。

04

关键岗位与核心人才 · Key Roles

哪些岗位和人才真正承载组织能力？识别关键岗位、核心人才画像、干部梯队、继任和人才池。

05

HR 机制输出 · HR Mechanisms

招聘配置、培训发展、绩效管理、薪酬激励、员工关系、组织发展/文化如何围绕组织能力联动。

方法论与工具

工具不是装饰，而是用来解决框架落地问题。每个工具都要说明输入数据、操作步骤、输出结果、管理决策和误用风险。

价值链分析定位业务价值创造与损失的位置。
组织能力地图把战略要求转成组织必须具备的能力。
Target Operating Model设计组织形式、治理、流程和资源配置机制。
RACI / RAPID澄清决策权、建议权、执行权和问责关系。
关键岗位识别找出真正影响业务结果和组织能力的岗位。
KPI / BSC / OKR把组织能力和关键岗位转成可管理的目标与指标。

实践与问题

真正的专业度，体现在能预判落地阻力，并把框架转成制度、流程、模板、指标和人才机制。

业务方不认同 HR 诊断

从价值链和经营指标切入，用业务数据证明问题。

组织能力说不清

把口号转成行为、流程、岗位、指标和机制。

组织形式选错

先判断价值链复杂度和能力需求，再选择组织形态。

权责机制不清

用授权表、RACI/RAPID、例会和问责机制澄清。

关键岗位泛化

按业务影响、稀缺性、替代成本、风险暴露度筛选。

数据口径争议

先统一指标定义、数据来源和使用场景。

如何使用

安装到 Codex skills 目录后，用自然语言调用即可。

使用 $hr-deep-research，深度研究项目工作的人力资源管理 使用 $hr-deep-research，研究多品牌多渠道公司如何做组织诊断 使用 $hr-deep-research，建立连锁零售企业关键岗位与组织能力的研究框架
