# Contributing / 贡献指南

欢迎改进这个 HR 深度研究 skill。

Contributions are welcome. This skill is designed for deep HR research, not for collecting disconnected concepts.

## 贡献方向 / Contribution Areas

请围绕三部分贡献内容：

Please contribute around the following three areas:

```text
一、分析框架 / Analytical Framework
二、方法论与工具 / Methodologies and Tools
三、实践与问题 / Practice and Problems
```

## 一、完善分析框架 / Improve the Analytical Framework

核心链条是：

The core chain is:

```text
价值链 / Value Chain
-> 关键组织能力 / Key Organizational Capabilities
-> 组织形式与组织机制 / Organization Forms and Mechanisms
-> 关键岗位与核心人才 / Key Positions and Core Talent
-> HR 机制输出（六大模块） / HR Mechanism Outputs (Six Modules)
```

贡献者可以补充：

Possible contributions:

- 不同行业的价值链分析方式 / Value chain analysis patterns for different industries
- 价值链如何推导关键组织能力 / How value chains derive organizational capabilities
- 组织能力如何对应组织形式 / How capabilities map to organization forms
- 组织机制如何设计 / How to design mechanisms such as accountability, decision rights, collaboration, budgeting, cadence, and performance review
- 关键岗位与核心人才如何识别 / How to identify key positions and core talent
- HR 六大模块如何围绕组织能力联动输出 / How the six HR modules align around organizational capabilities

框架类内容必须说明：

Framework contributions should explain:

- 解决什么经营问题 / What business problem it solves
- 适用于什么公司阶段或业务场景 / Which company stage or business context it fits
- 需要哪些数据验证 / What data is needed for validation
- 由谁负责推动 / Who should drive it
- 如何判断有效 / How effectiveness is judged

## 二、补充方法论与工具 / Add Methodologies and Tools

方法论与工具的作用是让分析框架能落地。

Methodologies and tools should operationalize the analytical framework.

欢迎补充头部咨询公司或成熟管理实践中的工具，例如：

Examples of useful tools include:

- 价值链分析 / Value chain analysis
- 商业模式和利润模型拆解 / Business model and profit model decomposition
- 组织能力地图 / Organizational capability map
- Target Operating Model
- 组织健康诊断 / Organization health diagnosis
- RACI / RAPID
- 管理跨度与组织层级分析 / Span-and-layer analysis
- 关键岗位识别 / Key position identification
- 岗位价值评估 / Role or position valuation
- 人才盘点与九宫格 / Talent review and 9-box
- 能力模型和成功画像 / Competency model and success profile
- KPI / BSC / OKR
- 激励有效性分析 / Incentive effectiveness analysis
- 变革影响分析 / Change impact analysis
- 利益相关方分析 / Stakeholder analysis

新增工具时，请写清楚：

When adding a tool, explain:

- 工具定义 / Definition
- 适用场景 / Use cases
- 对应框架中的哪一环 / Which framework step it supports
- 输入数据 / Input data
- 操作步骤 / Operating steps
- 输出结果 / Outputs
- 支持的管理决策 / Management decisions it supports
- 误用风险 / Misuse risks

## 三、补充实践与问题 / Add Practice and Problems

实践与问题部分关注：框架和工具在真实组织中为什么落不下去，以及如何解决。

This section focuses on why frameworks and tools fail in real organizations and how to solve those failures.

欢迎补充：

Possible topics:

- 业务方阻力 / Business resistance
- 数据口径争议 / Data definition disputes
- 权责不清 / Unclear accountability
- 部门墙 / Functional silos
- 干部能力不足 / Leadership capability gaps
- 激励冲突 / Incentive conflicts
- 组织调整阻力 / Organization change resistance
- 员工关系风险 / Employee relations risks
- 变革沟通问题 / Change communication issues
- 机制落地失败案例 / Failed implementation cases
- 高质量解决方案 / High-quality solutions

实践类内容建议包含：

Practice-oriented contributions should include:

- 真实业务场景 / Real business context
- 相关角色 / Stakeholders
- 冲突点 / Conflict points
- 数据争议 / Data disputes
- 推动顺序 / Implementation sequence
- 沟通机制 / Communication mechanism
- 风险控制 / Risk control
- 最终沉淀成什么制度、流程、模板、指标或人才机制 / What policy, process, template, metric, or talent mechanism should be institutionalized

## 提交原则 / Submission Principles

- 不加入个人隐私或公司敏感信息 / Do not include personal privacy or company-sensitive information.
- 不把临时案例写成通用事实 / Do not turn temporary cases into universal facts.
- 明确区分事实、来源综合和专业推断 / Distinguish facts, source-based synthesis, and professional inference.
- 保持输出结构：分析框架 -> 方法论与工具 -> 实践与问题 / Keep the structure: analytical framework -> methodologies and tools -> practice and problems.
- 优先写可落地的机制、步骤、数据和判断标准 / Prefer executable mechanisms, steps, data, and judgment criteria.
- 避免只增加概念名词或空泛口号 / Avoid adding only concept names or slogans.
